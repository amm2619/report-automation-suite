routeWorkflow

Every report follows the same six steps. Skim this once, then use the per-report cards below for the details that differ.

  1. 1
    Load your CSVs — drop Jira exports onto the header drop zone. The app auto-detects Issues / Epics / Roadmap by header sniffing, so order doesn't matter. See Files for the exact JQL queries.
  2. 2
    Configure once — Jira URL, sprint calendar, component filters, topic rules. Settings auto-save to your browser. See Configuration.
  3. 3
    Pick a report from the home screen. Each card shows what it needs and whether your current CSVs satisfy it.
  4. 4
    Set parameters — date range (Weekly), current + future sprint (EOS), month (PMR), or auto-detect (Sprint, Spin).
  5. 5
    Generate & review — fill in BLUFs, topic summaries, and PMR narratives directly in the report. Use the Debug tab to trace any surprise routing and + Include or + Create Rule to fix it inline.
  6. 6
    Export — Copy for Confluence or Email, Download PPTX (PMR), or Download VBA (Sprint). Save Draft before closing so you can pick up where you left off next time.
